About the data

Transparent sources
Live rating

The rating board calls the official Lichess API directly, so it reflects the current top Racing Kings players rather than a manually maintained list.

Official titles

Title holders come from this site's player/title data. With the current database empty, the board correctly reports that there are no holders yet.

Tournament records

Historical arena boards are sourced from Lichess Arena Rankings by Thijs. The repository refresh job keeps a local JSON snapshot so GitHub Pages can display it reliably.
