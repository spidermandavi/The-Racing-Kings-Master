Player Report

The Lichess Games API is queried for Racing Kings PGNs with clocks, engine evaluations and opening tags. Requests are cancellable. A selected date range is automatically split into smaller ranges when the per-request limit is reached.

Racing Kings board rules: the real pawnless Racing Kings starting position is used; there is no castling, checks are forbidden, kings may not move into check, and the first king to reach the 8th rank wins (with the standard immediate-reply draw condition).
Variant

The API request uses rated=true/false, tags=true, clocks=true, evals=true, opening=true, perfType=racingKings and the selected UTC date range.

Training filters

Filters update the current report immediately; fetching is only needed to change the underlying game sample.
