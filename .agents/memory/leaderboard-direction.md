---
name: Leaderboard visual direction
description: The chosen visual pattern for the Racing Kings leaderboard.
---

The leaderboard should balance spectacle and utility: use a podium-style spotlight for the leading three players, followed by a compact competitive table for scanning and comparison.

**Why:** The user preferred the Arena and Competitive Table concepts together rather than choosing only one.

**How to apply:** Preserve the existing title/member filters, profile navigation, Lichess links, and expandable real stats when iterating on the leaderboard.
